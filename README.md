# green-api-demo

## Локальный запуск

Перед запуском проверьте, что в `.env` указан актуальный API URL (`VITE_API_URL`).

```bash
npm i
npm run build
npm run preview
```

После сборки приложение доступно по адресу http://localhost:4173.
